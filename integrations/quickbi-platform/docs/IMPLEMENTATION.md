## 工程门禁

- `npm test` 必须覆盖跨租户数据泄露、角色拒绝、CSRF、SQL 参数安全、仪表板版本冲突及真实数据闭环。
- 该阶段**不启用**默认的 Harness Shell / FS / 自修改插件权限。仅将受控查询结果交给显式启用的独立 SDK 解释层。
- 真实外部连接器、复杂报表、高权限操作和多用户空间 ACL 仍需独立的安全设计与测试。
