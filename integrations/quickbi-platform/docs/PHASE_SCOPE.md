# 两期交付范围（2026-11-04，取代原 M0–M6 实施顺序）

> 本文是当前项目的**实施范围基线**。原全平台矩阵保留作历史功能索引，但不再代表必须开发的功能；不再以“完整复刻传统 Quick BI”为本次交付目标。下列“范围内”不等于“已经实现”。

## 一期（P1）：AIPro + 数据接入，形成真实业务闭环

目标：用户完成登录与授权后，能够连接真实的业务数据库、识别表结构、选择数据集和指标，在 AIPro 中自然语言分析数据、继续追问、生成图表/分析作品、保存并重开，所有查询均受权限和资源约束。

1. **数据接入（直连，不 ETL）**
   - MySQL、PostgreSQL 优先；兼容性测试涵盖 TiDB、StarRocks；后续再考虑 API/文件。
   - 连接信息使用加密凭据引用（不能把明文密码放在 API JSON/日志/浏览器持久存储）；连接测试、schema/table/column 发现、预览、连接池和超时。
   - 限制到只读数据库账号，允许配置 schema/table 白名单、查询超时与行数上限；生产环境必须约束内网 SSRF/网络目标。
   - 单表优先，必要时受控关联；**不提供**转换、清洗、同步、物化或定时装载流水线。
2. **必要语义层**
   - 数据集与指标、维度定义；业务名称、字段描述、时间口径；数据源到 QuerySpec 的白名单编译。
   - 租户/工作空间/资产授权；受控查询和审计；为 AI 和后续看板复用同一查询接口。
3. **AIPro 主功能**
   - 对话分析：会话创建/历史、上下文追问、分析意图与计划、工具调用、查询证据、错误恢复。
   - 图表与作品：以结构化 Artifact（含 QuerySpec、指标版本、结果来源）生成可编辑图表、表格和分析总结；保存、重新打开、版本更新。
   - 画布：把图表/说明添加到画布，支持布局与保存；第一期交互重点放在分析复用，不追求二期仪表板设计器的全部能力。
   - 分析主题：关联数据集、知识说明与可用技能；主题草稿/发布、权限控制；受控扩展 MCP。
   - Harness：使用独立 Agent Runtime/SDK，工具通过受控 BI 服务访问数据；模型不得获得直连数据库凭据或默认 Shell/FS 权限。
4. **支撑能力（仅必需）**
   - 登录、租户/工作空间、最小 RBAC/资产 ACL、审计、基础监控与自动化测试。
   - 不为了复刻管理中心全部菜单而推迟一期闭环。

### 一期验收门槛（必须由真实数据源证明）

- [ ] 从 Web 界面配置 PostgreSQL/MySQL 或 TiDB/StarRocks 真实连接，测试、发现 Schema、查看样本；数据源重启后仍可使用。
- [ ] 授权用户建立数据集和指标；AIPro 首问生成可审计 QuerySpec，后端只读执行并返回真实结果。
- [ ] 多轮追问可沿用同一数据集/指标上下文；生成图表与说明；保存 Artifact/Canvas，重新打开后结果与配置一致。
- [ ] 数据库报错、超时、空结果、错误指标和无权限时有可诊断的失败路径；不能泄露连接口令。
- [ ] 不同租户与不同角色的读取、分享、AI 工具路径均通过越权负例；审计记录具有查询与会话关联。
- [ ] Harness 真正参与分析决策和工具调度；仅用规则匹配问句或给查询结果润色**不算**完成 AIPro。

## 二期（P2）：图表 + 仪表板/看板

在一期同一查询引擎、指标体系和权限服务上扩展：

- 图表组件：柱/折/饼/表格/指标卡等；图表配置与查询协议分离。
- 看板设计器：拖拽、尺寸布局、配置编辑、筛选联动、钻取、保存、发布、分享和只读访问。
- 看板数据刷新与错误状态；图表结果与 AIPro Artifact 可以相互复用。
- 不把仪表板的基础原型当成完整看板交付：交互编辑、联动、发布、权限与回归必须单独验收。

### 二期验收门槛

- [ ] 通过数据集创建看板，拖拽编辑两类以上图表，设置过滤联动并保存发布。
- [ ] 同一个指标在 AIPro 和看板中结果一致；数据和权限变更后按预期刷新/拒绝。
- [ ] 至少包含布局持久化、版本冲突、筛选、权限负例的自动化回归。

## 从本次两期范围明确剔除

- **ETL 全部移除**：不实现数据准备 ETL、数据清洗/转换、批量同步、抽取加速、数据处理 Pipeline。
- 传统 BI 其余产品形态暂不开发：电子表格、大屏、数据填报、门户、完整自助取数等。
- 企业级全功能市场、泛化运营后台等非一期闭环必需项暂缓；已有基础页可以保留但不继续扩张。
- 不重建 Quick BI 专有内部实现、专有代码/素材；仅实现独立且功能对标的产品。

## 近期顺序（以端到端证据为验收）

| 顺序 | 工作包 | 证据 |
|---|---|---|
| 1 | 数据源 SPI + 真连接器、凭据隔离、真实元数据 | 创建→测试→预览可复测 |
| 2 | 跨源数据集、语义指标、受控 QuerySpec | 真实库受限查询 + 权限负例 |
| 3 | Harness BI 工具、分析规划、会话上下文 | 多轮 Agent 工具调用与 trace |
| 4 | AIPro 分析主题、Artifact、画布 | 保存/重开/编辑 + 共享权限 |
| 5 | 一期全链路验收 | 跨租户、错库/超时、安全、实际数据正确性 |
| 6 | 二期图表/看板 | 可编辑、联动、发布、权限与回归 |

## 现有仓库的真实进度

截至 2026-11-04，`integrations/quickbi-platform` 只实现了基础认证/租户/审计、SQLite 演示源、演示数据集、受限 SQLite 查询、简单看板原型和确定性问数；Harness 目前仅作为可选解读接入。**一期尚未完成**：真实数据库接入、企业凭据隔离、完整 AIPro Agent、持久会话/作品/画布、权限细分仍需实现。现有仪表板原型保留但冻结，二期再扩展。
